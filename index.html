FacePercept-Bench

Do synthetic faces sit closer to the centre of vision-model face space?

A reproducible computational demo comparing real and AI-generated faces across CLIP, DINOv2, SigLIP, and Qwen2.5-VL.

View GitHubSee result

Key finding

Across three independent vision encoders, synthetic faces were consistently closer than real faces to a reference centroid estimated only from real faces in the training split, while remaining strongly separable from real faces.

Question this raises

Does representation-space centrality in modern vision models relate in any meaningful way to the perceptual averageness or hyper-realism effects reported for AI-generated faces in humans?

This demo does not equate embedding geometry with human perception. It provides a computational starting point for testing that relationship.

VLM behaviour

Qwen2.5-VL-3B did not show a supported machine-side hyper-realism effect. It predicted REAL for both classes at nearly the same rate, so that result is treated as a near-constant-response failure mode rather than a positive effect.
